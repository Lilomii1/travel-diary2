## Обнаруженные ошибки

### Ошибка 1. Мелкое подвисание при загрузке больших фото

- **Проявление:** при загрузке фото >5 МБ браузер «задумывается» на 1–2 секунды.
- **Причина:** canvas перерисовывает слишком большое изображение.
- **Решение:** ограничение `maxSize = 1200px` и `quality = 0.8` 
  в `photos.js`.

### Ошибка 2. Перекрытие подписей городов на карте

- **Проявление:** при близко расположенных маркерах подписи наезжают 
  друг на друга.
- **Решение:** добавлена кнопка «🏷 Скрыть подписи» для управления 
  видимостью.
