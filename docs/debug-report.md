## Найденные ошибки

### Ошибка 1. `Storage is not defined`

- **Тип:** ошибка интеграции
- **Где:** `src/index.html`
- **Симптом:** при открытии приложения — белый экран, в Console ошибка
- **Причина:** после разделения `app.js` на модули (день 5) файл `storage.js` 
  не подключён в HTML
- **Решение:** добавлена строка `<script src="storage.js"></script>` 
  перед `app.js`
- **Статус:** ✅ исправлено
- **Коммит:** `fix: подключён storage.js в index.html`

### Ошибка 2. `Auth is not defined`

- **Тип:** ошибка интеграции
- **Где:** `src/index.html`, порядок скриптов
- **Симптом:** регистрация не работает
- **Причина:** `storage.js` подключён **раньше** `auth.js`, а `storage.js` 
  использует `Auth`
- **Решение:** изменён порядок — `auth.js` теперь идёт **первым**
- **Статус:** ✅ исправлено
- **Коммит:** `fix: auth.js подключается раньше storage.js`

### Ошибка 3. Неверный формат даты

- **Тип:** логическая
- **Где:** `src/app.js`, функция `handleSubmit`
- **Симптом:** дата отображается как `2026-9-1` вместо `2026-09-01`
- **Причина:** `new Date().toISOString()` убирает ведущие нули
- **Решение:** использовать значение поля `<input type="date">` **напрямую** 
  (оно уже в формате `YYYY-MM-DD`)
- **Статус:** ✅ исправлено
- **Коммит:** `fix: дата сохраняется в формате YYYY-MM-DD`

### Ошибка 4. Фото не сжимались

- **Тип:** ошибка времени выполнения
- **Где:** `src/photos.js`, `compressImage`
- **Симптом:** `Failed to execute 'drawImage' on 'CanvasRenderingContext2D'`
- **Причина:** canvas рисовал изображение до его полной загрузки
- **Решение:** добавлен обработчик `img.onload` **перед** `img.src = ...`
- **Статус:** ✅ исправлено
- **Коммит:** `fix: корректное сжатие фото через canvas`

### Ошибка 5. Статистика показывала 0 км

- **Тип:** логическая
- **Где:** `src/app.js`, `renderAll`
- **Симптом:** поле «Км пройдено» = 0 при наличии поездок
- **Причина:** `renderStats()` вызывался **до** `renderTrips()`
- **Решение:** `renderStats()` теперь после `renderTrips()`
- **Статус:** ✅ исправлено
- **Коммит:** `fix: статистика считается после загрузки поездок`

### Ошибка 6. Клик по карте не работал

- **Тип:** ошибка интеграции
- **Где:** `src/main.js`
- **Симптом:** клик по карте не подставляет координаты
- **Причина:** `window.__onMapClick` регистрировался **после** `TravelMap.init()`
- **Решение:** обработчик регистрируется **до** инициализации карты
- **Статус:** ✅ исправлено
- **Коммит:** `fix: обработчик клика регистрируется раньше init`
