# Стандарты кодирования

## Именование

| Элемент | Стиль | Пример |
|---------|-------|--------|
| Переменные | camelCase | tripId, startDate |
| Константы | UPPER_SNAKE_CASE | MAX_PHOTO_SIZE |

- Кавычки: одинарные
