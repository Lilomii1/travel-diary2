# 🌍 Дневник Путешественника

Веб-приложение для ведения личного дневника путешествий
с визуализацией на карте, статистикой и фотографиями.

## Возможности

- 🔐 Регистрация и вход (пароль — SHA-256)
- ✈️ CRUD поездок
- 🗺️ Карта Leaflet + Яндекс.Карты
- 📍 Выбор точки кликом по карте
- 📷 Фотографии с автосжатием
- 📊 Статистика: страны, города, дни, км
- 🔍 Фильтры, поиск, сортировка
- 🌓 Тёмная / светлая тема
- 📤 Экспорт в JSON и CSV
- 📥 Импорт из JSON

## Структура

- `src/` — исходный код
- `docs/` — документация
- `data/` — примеры данных
- `tests/` — unit-тесты

## Запуск

⚠️ **Важно:** Web Crypto API (SHA-256) работает только на `http://localhost` или `https://`,
НЕ на `file://`. Поэтому открывайте через Live Server или:

```bash
python -m http.server 8080
